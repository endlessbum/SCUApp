## Настройки в открытом диалоге Vercel (важно!)

1. **Обязательно поставьте галочку «Add a read-write token env var to this connection»** — на скриншоте она снята. Без неё не создастся `BLOB_READ_WRITE_TOKEN`, и `api/track.js` не сможет ни писать маркеры, ни читать счётчики (функция будет отдавать 500, строки-счётчики на сайте не появятся).
2. **Access: оставьте Private (Recommended)** — это правильный выбор. Наши маркеры (только timestamp, путь = SHA256-хеш) не должны быть доступны кому угодно по URL; SDK читает/пишет их через токен, публичный доступ не нужен.
3. Имя (`scu-app-blob`) и регион (iad1) — оставляйте как есть, роли не играет.
4. После Create, если Vercel не предложит редеплой сам — сделайте Redeploy проекта (переменные окружения применяются при следующем деплое).

## Изменение в коде (1 строка)

В `api/track.js` сменю `access: 'public'` на `access: 'private'` в вызове `put()` — чтобы тип доступа в коде совпадал с Private-стором (SDK v2.8.0 это поддерживает, при несовпадении сервер может отклонить запись).

## Проверка после деплоя

Открыть сайт — под «Последнее обновление» должны появиться строки «Посещений: N» и «Загрузок: N». Обновить страницу пару раз — число не должно вырасти (дедупликация по SHA256). Кликнуть «Скачать» и вернуться — «Загрузок» +1 только один раз.
